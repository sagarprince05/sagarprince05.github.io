Price Intelligence Pipeline

A scheduled Python pipeline that collects product prices from several online marketplaces, normalises very different pricing models into one schema, and stores current prices plus full history in PostgreSQL.

The problem

Prices in this market change daily across several marketplaces, and checking hundreds of product variants by hand is impossible. The team needed to know, at any moment, the best price currently available for each product they sell.

What I built

  • A single-file Python collector with one adapter per source behind a common interface, so a new source is a small, isolated addition.
  • Schema normalisation — percent discounts, flat discounts, denomination-level variants and multi-seller listings all reduced to one consistent shape.
  • Fast, polite collection. A 16-worker thread pool with retry, backoff and request throttling completes a full run in about 35 seconds.
  • Price history built in. Each run upserts current prices and appends an immutable snapshot, which makes price-over-time analysis possible.
  • Analytics as SQL views so the answer to "what do we need to beat?" is a single query rather than a script.
  • Zero-cost scheduling on a CI cron every 12 hours, with a manual trigger — no server to maintain.
  • Read-only API access via row-level security policies, so a frontend can read live comparison data while only the pipeline can write.
