Voucher Price Tracker — competitor price intelligence

An end-to-end competitor price-intelligence pipeline for the gift voucher / gaming credits market (BGMI UC, Google Play, Steam keys). It answers one question at any moment: which competitor is cheapest for every product I sell?

The problem

Voucher pricing is hyper-competitive — discounts change daily across marketplaces, and manually checking hundreds of denominations on four different sites is impossible. To price competitively, I needed to know at any moment which competitor is cheapest for every product I sell.

The solution

A single-file Python scraper that reverse-engineers the internal APIs of four competitor platforms (Swag, GyFTR, 99gift, Rooter), normalises their very different data models — percent discounts, flat discounts, denomination-level SKUs, multi-seller listings — into one schema, and syncs everything to a Supabase Postgres database.

How it works

  • Zero-cost, serverless scheduling — runs on a GitHub Actions cron every 12 hours (about 8:30 am and 8:30 pm IST), with a manual trigger from the GitHub page; no server to maintain.
  • Fast, polite scraping — a 16-worker thread pool with retry/backoff and request throttling completes a full scrape and database sync of ~2,200 products in about 35 seconds.
  • Catalogue-aware filtering — only scrapes products matching my own catalogue, cutting scrape volume dramatically.
  • Price history built in — every run bulk-upserts current prices and appends immutable snapshots, enabling price-over-time analysis.
  • Analytics as SQL views — v_my_compare shows every competitor offer matching each of my products; v_my_best returns one row per product: the cheapest competitor price to beat.
  • Frontend-ready security — row-level security policies and anon read grants mean any website can read live comparison data directly via the Supabase API, with the database writable only by the pipeline.
  • Per-site adapters, one config — each competitor has its own adapter behind a common interface; everything is configured through environment variables.
